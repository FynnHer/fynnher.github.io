GitHub is the reliable route. Open an issue on the relevant repository, or start a discussion — both reach me faster than anything else and keep the conversation where the code is.

On email

I deliberately don’t publish an address here — a plain mailto: on a public page collects far more spam than correspondence. If you need to reach me privately, say so in a GitHub issue or discussion and I’ll take it from there.

Good reasons to write

You’re working on a hobby kernel and hit the same wall I did. You fly drones for a rescue or civil protection organisation and need the imagery to become useful faster. You have geodata that needs to be readable in a browser. You think something on this site is wrong — especially then.
